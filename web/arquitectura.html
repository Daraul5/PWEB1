Arquitectura Cliente-Servidor

Es un modelo de diseño de software en el que las tareas se reparten entre los proveedores de servicios (servidores) y los demandantes (clientes).

Componentes Clave del Modelo

  • Cliente (Front-End): Dispositivo o navegador web del usuario que genera y envía las peticiones de recursos.
  • Servidor (Back-End): Sistema centralizado que recibe las peticiones, procesa la lógica de la aplicación y gestiona los datos.
  • Internet: El medio de red por el cual viajan los mensajes de ida (petición) y vuelta (respuesta).
  • Flujo de Comunicación: Intercambio bidireccional basado en solicitudes del cliente y respuestas del servidor.
