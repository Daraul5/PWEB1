El Protocolo HTTP

HTTP (Hypertext Transfer Protocol) es el protocolo de transferencia de hipertexto que permite la comunicación entre un cliente (como un navegador web) y un servidor. Funciona mediante un modelo de petición y respuesta:

  • Petición (Request): El cliente solicita un recurso al servidor indicando una URL y un método (por ejemplo, GET).
  • Respuesta (Response): El servidor procesa la solicitud y devuelve el recurso solicitado (código HTML, imágenes, datos) acompañado de un código de estado (como 200 OK o 404 No encontrado).

Tipos de URLs

Una URL (Localizador Uniforme de Recursos) es la dirección utilizada para acceder a un recurso en la web.

URL Absoluta

Contiene la dirección completa y exacta del recurso, incluyendo el protocolo, el dominio y la ruta completa. Se utiliza para enlazar páginas externas o recursos de otro sitio web.

https://www.tecnm.mx/acerca-del-tecnm/

URL Relativa

Especifica la ubicación del recurso en relación con la página actual, omitiendo el protocolo y el dominio. Es ideal para navegar dentro del mismo sitio web, asegurando que funcione sin conexión.

../web/historia.html (Para ir a la página de historia desde otra sección dentro de la carpeta web)
